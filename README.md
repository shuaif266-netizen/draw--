# Scientific Framework Skill

面向中文科研项目申报书、基金申请书和课题申请书的个人科研框架图 Agent Skill。

目标流程：申请书 → 科研内容理解 → 有来源的 Scientific IR → 科研逻辑检查 → 2–3 个结构方向 → 版式与个人视觉语法 → 可编辑 draw.io → SVG/PNG 预览 → 科研与视觉检查 → 人工反馈修订。

优先级：科研逻辑准确、结构清晰、阅读顺序明确、可编辑、视觉美观。

## 当前阶段

第一轮只做上游分析和架构设计。仓库尚未提供可安装 Skill 或可运行绘图流水线。完成分析后等待项目拥有者确认，再进入 Milestone 1。

最终 Skill 的计划路径是 `skills/scientific-framework/`。上游参考项目为 [Agents365-ai/drawio-skill](https://github.com/Agents365-ai/drawio-skill)，按具体模块选择借鉴，不整体复制仓库。

## 数据与示例

真实申请书、未公开科研材料、参考图片和人工意见默认保存在本机。公开示例使用合成或经允许的匿名材料。参考图学习视觉组织，不作为科研事实或因果关系来源。
